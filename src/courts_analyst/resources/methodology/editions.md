# Editions and revisions

An edition is one publication of a table: Judicial Business 2020 (JB-2020)
first publishes FY2020; Judicial Facts and Figures editions (JFF-2020 …
JFF-2025) repeat it and sometimes revise it.

- The server returns the **latest** edition's value by default and always
  attaches the first-published value and every revision.
- Pass `edition='first_published'` or an edition id for another value.
- Comparisons across courts use one edition; the server never averages or
  mixes editions.
- Revised figures: 1,340 in the catalog, listed in the `courts://revisions`
  resource. Most are prior-year pending counts restated in the next
  Judicial Business; the weighted per-judgeship series was revised for every
  year FY2016–FY2025.
